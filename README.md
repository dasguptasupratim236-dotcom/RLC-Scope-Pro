# RLC-Scope Pro ⚡

An interactive, web-based simulation engine built to analyze electrical networks, perform complex phasor impedance calculations, and model dynamic 3D transient responses in real time.

---

## Key Features

* **Real-Time Impedance Calculations:** Automates complex phasor and frequency-domain network calculations.
* **3D Transient Response Modeling:** Renders interactive 3D visualizations of system behaviors using Plotly.
* **Step-by-Step Analytical Solver:** Provides detailed mathematical breakdowns for transient and steady-state responses.
* **Web-Based Simulation Engine:** Built on top of Streamlit for rapid parameter tuning and instant visual feedback.

---

## Tech Stack

* **Language:** Python
* **Mathematics & Computing:** NumPy, SciPy
* **Data Visualization:** Plotly
* **Web Framework:** Streamlit
